# Env Diff Tool

Env Diff Tool is a simple tool for comparing environment files.
It helps you quickly identify added, removed, and changed variables, review comments, and generate a merged result.
The app is built with React, TypeScript, Vite, and Tailwind CSS, and is configured as a PWA.

## Local Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

This command starts Vite with hot module replacement for fast local iteration.

## Build for Production

Create a production build:

```bash
npm run build
```

This command runs TypeScript project checks and then builds optimized static assets into the dist folder.

Optional: preview the production build locally:

```bash
npm run preview
```

This starts a local server to validate the generated production output.
